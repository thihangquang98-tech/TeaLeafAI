
# TeaLeaf AI

## Tea Leaf Disease Classification Using Deep Learning

### 1. Project Overview

TeaLeaf AI is a Computer Vision project designed to
classify tea leaf diseases using Deep Learning.

### 2. Objectives

- Collect and analyze tea leaf image datasets.
- Build a multi-class image classification model.
- Train CNN and Transfer Learning architectures.
- Evaluate model performance.
- Develop an image classification application.

### 3. Technologies

- Python 3.10
- PyTorch
- OpenCV
- Albumentations
- Scikit-learn
- Google Colab
- Flask
